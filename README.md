# Интернет-магазин

Проект интернет-магазина с системой управления категориями и товарами.

## Функциональность

### В данном задании реализовано:

1. **Класс Product (Товар)**
   - Хранение информации о товаре
   - Атрибуты: название, описание, цена, количество

2. **Класс Category (Категория)**
   - Хранение информации о категории товаров
   - Атрибуты: название, описание, список товаров
   - Атрибуты класса: общее количество категорий и товаров

3. **Автоматический подсчет**
   - Автоматический подсчет количества категорий при создании
   - Автоматический подсчет общего количества товаров

4. **Тестирование**
   - Полное покрытие тестами основных функций
   - Тестирование инициализации объектов
   - Тестирование подсчетов

5. **Дополнительная функция**
   - Загрузка данных из JSON файла

### 2. Ограничения сложения товаров
- Реализована проверка типов при сложении товаров
- Можно складывать только товары одного типа
- При попытке сложить товары разных типов возникает `TypeError`

### 3. Защита метода добавления товаров
- Метод `add_product` в классе `Category` теперь проверяет, что добавляемый объект является экземпляром `Product` или его наследников
- Используется `isinstance()` для проверки

### 1. Абстрактный базовый класс `BaseProduct`

Создан абстрактный класс `BaseProduct`, который определяет общий интерфейс для всех продуктов:
- Абстрактные методы `__init__`, `__str__`, `__add__`
- Абстрактное свойство `price` с геттером и сеттером

Классы `Product`, `Smartphone` и `LawnGrass` теперь наследуют общую функциональность через этот базовый класс.

### 2. Миксин `ReprMixin`

Реализован класс-миксин, который автоматически печатает информацию о создании объектов:
- При создании любого объекта, наследующего от `ReprMixin`, в консоль выводится информация о классе и параметрах
- Миксин добавлен в цепочку наследования класса `Product`

### 3. Класс `Order`

Реализован новый класс для представления заказов:
- Содержит информацию о товаре, количестве и итоговой стоимости
- Один заказ может содержать только один товар
- Наследуется от общего абстрактного класса `BaseCategory` вместе с классом `Category`

### 4. Общий абстрактный класс `BaseCategory`

Создан абстрактный класс для вынесения общей функциональности классов `Category` и `Order`:
- Общие атрибуты: `name`, `description`
- Абстрактные методы: `__str__`, `__len__`
