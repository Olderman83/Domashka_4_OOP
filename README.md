# Интернет-магазин

Проект интернет-магазина с системой управления категориями и товарами.

## Функциональность

### В данном задании реализовано:

1. **Класс Product (Товар)**
   - Хранение информации о товаре
   - Атрибуты: название, описание, цена, количество

2. **Класс Category (Категория)**
   - Хранение информации о категории товаров
   - Атрибуты: название, описание, список товаров
   - Атрибуты класса: общее количество категорий и товаров

3. **Автоматический подсчет**
   - Автоматический подсчет количества категорий при создании
   - Автоматический подсчет общего количества товаров

4. **Тестирование**
   - Полное покрытие тестами основных функций
   - Тестирование инициализации объектов
   - Тестирование подсчетов

5. **Дополнительная функция**
   - Загрузка данных из JSON файла

### 2. Ограничения сложения товаров
- Реализована проверка типов при сложении товаров
- Можно складывать только товары одного типа
- При попытке сложить товары разных типов возникает `TypeError`

### 3. Защита метода добавления товаров
- Метод `add_product` в классе `Category` теперь проверяет, что добавляемый объект является экземпляром `Product` или его наследников
- Используется `isinstance()` для проверки
