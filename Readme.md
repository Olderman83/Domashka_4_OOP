# Проект "Управление товарами и категориями"

Проект представляет собой систему для управления товарами и категориями с возможностью загрузки данных из JSON-файла. Реализована иерархия классов с использованием абстрактных базовых классов, миксинов и обработкой исключений.

## Структура проекта
project/
─ src/
─ init.py
─ product.py # Классы для работы с продуктами
─ category.py # Классы для работы с категориями
─ order.py # Класс для работы с заказами
─ utils.py # Утилиты для загрузки данных

── tests/
─ init.py
─ test_product.py # Тесты для класса Product
─ test_category.py # Тесты для класса Category

── data/
─ products.json # Данные о категориях и товарах

─ main.py # Точка входа в приложение
─ README.md # Документация проекта

## Классы и их функциональность

### Базовые классы и миксины

#### ReprMixin (product.py)
Миксин для автоматического вывода информации о создании объекта. При инициализации объекта выводит сообщение с его представлением.

#### BaseProduct (product.py)
Абстрактный базовый класс для всех продуктов. Определяет обязательные методы:
- `__init__` - инициализация продукта
- `__str__` - строковое представление
- `__add__` - операция сложения продуктов
- `price` - геттер и сеттер для цены

#### BaseCategory (category.py)
Абстрактный базовый класс для категорий. Определяет обязательные методы:
- `__init__` - инициализация категории
- `__str__` - строковое представление
- `__len__` - получение количества элементов

### Основные классы

#### Product (product.py)
Класс для представления товара. Наследуется от `ReprMixin` и `BaseProduct`.

**Атрибуты:**
- `name` - название товара
- `description` - описание товара
- `price` - цена товара (приватный атрибут)
- `quantity` - количество товара на складе

**Методы:**
- `__init__(name, description, price, quantity)` - создает товар с проверкой количества
- `__str__()` - возвращает строку с информацией о товаре
- `__repr__()` - возвращает представление для отладки
- `__add__(other)` - складывает стоимость товаров одинакового типа
- `new_product(cls, product_data)` - создает товар из словаря
- `price` - геттер для получения цены
- `price.setter` - сеттер с проверкой на отрицательное значение

**Исключения:**
- `ValueError` - если при создании товара указано нулевое количество

#### Smartphone (product.py)
Наследник класса `Product`. Добавляет атрибуты:
- `efficiency` - производительность
- `model` - модель смартфона
- `memory` - объем памяти
- `color` - цвет

#### LawnGrass (product.py)
Наследник класса `Product`. Добавляет атрибуты:
- `country` - страна-производитель
- `germination_period` - срок прорастания
- `color` - цвет

#### Category (category.py)
Класс для представления категории товаров.

**Атрибуты класса:**
- `category_count` - количество созданных категорий
- `product_count` - общее количество товаров во всех категориях

**Атрибуты экземпляра:**
- `name` - название категории
- `description` - описание категории
- `__products` - список товаров в категории (приватный)

**Методы:**
- `__init__(name, description, products)` - создает категорию и добавляет товары
- `__len__()` - возвращает количество товаров в категории
- `__str__()` - возвращает строку с названием и общим количеством товаров
- `products` - геттер для получения списка товаров в форматированном виде
- `add_product(product)` - добавляет товар в категорию с проверкой типа

#### Order (order.py)
Класс для представления заказа. Наследуется от `BaseCategory`.

**Атрибуты:**
- `product` - товар в заказе
- `quantity` - количество товара
- `total_price` - общая стоимость заказа

**Методы:**
- `__init__(product, quantity)` - создает заказ
- `__str__()` - возвращает строку с информацией о заказе
- `__len__()` - возвращает количество товаров в заказе

### Утилиты

#### utils.py
- `load_categories_from_json(file_path)` - загружает категории и товары из JSON-файла
